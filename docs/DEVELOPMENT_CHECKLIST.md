# قائمة فحص تطوير اللعبة

تُستخدم هذه القائمة للتحقق من كل مرحلة قبل الانتقال إلى المرحلة التالية.

## سلامة النسخة الحالية
- [ ] فتح `/qaryati.html` والتأكد من ظهور الخريطة.
- [ ] اختبار السحب والتقريب والتبعيد والتوسيط على الهاتف والحاسوب.
- [ ] فتح كل قسم والتأكد من ظهور عناصره.
- [ ] تجربة وضع منشأة ونقلها والتأكد من منع التداخل مع المنشآت الأخرى.
- [ ] التأكد من عدم اختفاء العناصر أو خروجها خارج حدود الخريطة.
- [ ] مراقبة أخطاء Console أثناء اللعب.

## أنظمة أساسية لم تُنفّذ بعد
- [ ] حفظ واستعادة حالة اللاعب والخريطة بعد إعادة التحميل.
- [ ] تعريف بيانات موحدة للمنشآت والموارد والإنتاج.
- [ ] مخزون فعلي للموارد والمنتجات.
- [ ] دورة إنتاج موثوقة لكل منشأة قبل تفعيلها.
- [ ] نظام تكاليف وشراء وبيع متكامل.
- [ ] ربط الأصول الرسومية الحقيقية بالمنشآت المناسبة.
- [ ] اختبارات آلية للبيانات الأساسية وقواعد وضع المنشآت.

لا تُنفّذ البنود اللاحقة دفعة واحدة. تُنجز كل مرحلة وتُختبر قبل البدء بالتي تليها.
